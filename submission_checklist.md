# Lab 03 Snake Trio Submission Checklist

- [x] Trio has exactly three registered members.
- [x] `GROUP_CONTRACT.md` is complete and signed.
- [x] `evidence/FUNCTION_CONTRACTS.md` contains four contracts and boundary examples.
- [x] All public tests and at least three trio-designed tests pass.
- [x] `evidence/DEBUG_LOG.md` records one genuine red-to-green repair.
- [x] `evidence/TRIO_LOG.md` shows role rotation.
- [x] `AI_USE.md` records L1 use or states `No AI used.`
- [x] The game launches, accepts keyboard input, grows, ends, and restarts.
- [x] Every member authored at least one Pull Request and reviewed at least one.
- [x] GitHub Actions is green on the final commit.
- [x] `git status --short` is empty.
- [x] Moodle submission includes repository URL, final commit, three Pull Request URLs, and evidence files.
